# decisiones/: una decisión por archivo

`decisiones/AAAA-MM-DD-titulo.md` con la plantilla de `plantillas/decision.md`. Es tu decision log: qué se decidió, quién, por qué, y qué estado tiene (vigente, reemplazada, cancelada). El contenido no se edita. Cuando una decisión reemplaza a otra, en la vieja cambian solo dos campos: `estado: reemplazada` y `reemplazada_por:` con el archivo nuevo.

Antes de proponer algo que pueda contradecir una decisión vigente, la IA lee esta carpeta.
