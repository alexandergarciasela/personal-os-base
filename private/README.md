# private/: originales y material confidencial

Durante el taller queda vacía, salvo este archivo.

Guarda aquí originales (transcripciones, correos) o material confidencial solo si puedes tratarlo en la cuenta y la herramienta que usas. Nunca contraseñas, claves ni tokens.

## El nombre no protege
Esta carpeta no cifra nada ni impide que una aplicación la lea. `.gitignore` deja fuera de git lo nuevo que pongas aquí (salvo este archivo), pero no saca lo que git ya hubiera registrado, ni la excluye de un ZIP, una copia manual o una sincronización.

## Qué sale de aquí
Para trabajar con un original, dile a Claude qué archivo. Al resto de la carpeta llega solo el resumen sin información confidencial. No subas esta carpeta a un proyecto de claude.ai ni la compartas con la base. Si la respaldas, hazlo aparte y en un lugar adecuado para ese material.
