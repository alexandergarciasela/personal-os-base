# reuniones/: una síntesis por reunión

`reuniones/AAAA-MM-DD-tema.md` con la plantilla de `plantillas/reunion.md`. La escribe `archiva-reunion` desde lo que pegaste en `crudo/` o desde lo que dictaste. Qué se decidió, qué quedó abierto, con quién, y el seguimiento listo para pegar.

La síntesis no es la lista de pendientes: los pendientes van a `abiertos.md` o a tu herramienta, una sola vez.
